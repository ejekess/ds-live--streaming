# 我给虚拟主播做了个"会心疼钱"的大脑

> 不用真人出镜，一只 AI 鲸鱼娘替你直播：读弹幕、按打赏档位做反应、还能和观众玩猜词。
> 全套跑在你自己电脑上，OBS 叠一层浏览器源就上播。

## 为什么做这个

我看了很多虚拟主播，形象一个比一个精致，但**"反应"是死的**：

- 弹幕照念，不管说什么都是同一句"谢谢宝宝"
- 礼物只会说谢谢，送一块和送一万没有区别
- 观众刷完就走，因为没有"留下来的理由"

所以我把重点放在两件事上：

**① 打赏要分级。** 让人一眼看出"她注意到我花了多少钱"——这是直播最朴素的驱动力。

**② 不花钱的观众也得有事干。** 猜词游戏就是给他们的：不用送礼，发个数字就能参与。

## 怎么跑起来

### 第一步：环境

```powershell
git clone https://github.com/ejekess/ds-live--streaming.git
cd ds-live--streaming
npm install          # 只有 ws 和 protobufjs
node src/index.mjs
```

看到这两行就成了：

```
舞台（OBS 浏览器源）： http://127.0.0.1:8787/avatar
管控台：               http://127.0.0.1:8787/admin/
```

### 第二步：接进 OBS

来源 → `+` → **浏览器**：

| 字段 | 值 |
| --- | --- |
| URL | `http://127.0.0.1:8787/avatar?bg=gradient` |
| 宽高 | 1920 × 1080 |

背景透明，叠在你自己的画面上就行。不想开 OBS 的话，直播伴侣里用「窗口捕获」抓这个页面也可以。

### 第三步：接真实弹幕

默认用的是 mock 剧本（假弹幕），方便调试。要接真直播间：

```powershell
node tools\live.mjs 你的房间号
```

重启服务，日志出现这行就通了：

```
[cdp] 已挂上推送信道： wss://webcast100-ws-web-...
```

**注意**：抓取会在浏览器里打开你的直播间页面，需要**扫码登录一次**（匿名看不了弹幕），登录态会存下来。

### 第四步：玩一局

管控台「猜词小游戏」→ 开一局。

观众在直播间发数字就行：

| 阶段 | 发什么 |
| --- | --- |
| 选题 | `1` / `2` / `3` 挑一个问题 |
| 回答 | `1`-`4` 选答案，`0` 表示不确定 |

![选题](screenshots/game-2-pick.png)

五轮之后揭晓答案：

## 设计上最花时间的四个决定

这部分是我觉得真正值得说的。

### ① 为什么用"浏览器旁听"而不是自己连抖音

网上现成的方案都是自己算签名去连抖音的 WebSocket。问题是：那个签名算法（`a_bogus`）平台一改就全废，你得一直跟着修。

我反过来做——**用本机浏览器打开直播间，让它自己完成握手，我们只旁听它收到的数据帧**。浏览器替我们处理了签名、心跳、登录态，我们只管解 protobuf。

代价是要开一个浏览器窗口，但换来的是**不怕平台改签名**。

### ② 为什么答案不能进模型

反向猜词的关键是"她不知道答案"。这件事我用**数据结构**保证，不是靠提示词：

```
答案存在游戏对象里 → 快照里揭晓前是 null → 台词里根本没有这个词
```

给舞台画面用的字段刻意叫 `displayWord`，不叫 `word`——防止有人顺手把它拼进 prompt。

同理，模型能做决策，但**没有结束游戏的权力**：它只输出"我猜是 XX"，对错由程序比对。

### ③ 为什么语音要排队

第一版是"合成完就播，下一条来了直接顶掉"。结果观众看到的是：**字已经跳到下一句，声音还卡在上半句**。

改成串行队伍：一次只说一句，说完才说下一句，气泡和音频同时出现。代价是高峰期延迟几秒，但"晚说一句"比"说半句被掐"好得多。

### ④ 为什么给游戏预留额度

大模型有每日调用上限。测试时发现：直播间弹幕一多，闲聊把额度吃光，**猜词决策一次都排不上**——游戏照常跑，只是从"她在思考"退化成"她一直问到底"，还不报错。

修法是给游戏预留 20%：闲聊用到 80% 就停。

## 踩过的坑（都是"不报错但静默失效"）

| 现象 | 真因 |
| --- | --- |
| 抓到帧却解不出事件 | 抖音把 gzip 报文标成 `pb`，我信了字段名没解压 |
| 开场动画从来没出现过 | 分发钩子时漏转发一个，事件发了没人接 |
| 页面全超时但接口正常 | 父进程退出后日志管道写满，事件循环被堵死 |
| 改了代码页面不更新 | OBS 浏览器源缓存页面，不会自动重载 |

共同点：**光看代码看不出来，必须真跑一遍**。
