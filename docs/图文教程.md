# 我给虚拟主播做了个"会心疼钱"的大脑

> 不用真人出镜，一只 AI 鲸鱼娘替你直播：读弹幕、按打赏档位做反应、还能和观众玩猜词。
> 全套跑在你自己电脑上，OBS 叠一层浏览器源就上播。

---

![待机](screenshots/game-0-idle.png)

有人送礼物，她会**按金额换反应**——小心心只是点头，跑车就喷水撒花，嘉年华直接烟花齐放：

![打赏 T4](screenshots/stage-gift-t4.png)

## 二、它由哪些部分组成

整套东西跑在本地一个 Node 进程里，没有云服务。

| 模块 | 干什么 |
| --- | --- |
| 弹幕源 | 四种：mock（假弹幕，调试用）、replay（回放）、exec（外部程序）、cdp（真直播间） |
| 解码器 | 把抖音的 protobuf 字节流翻译成弹幕、礼物、点赞、进场 |
| 编排器 | 决定"这条弹幕要不要回""这个礼物该怎么演" |
| 演出队列 | 连刷礼物会排队，不会互相打断 |
| 语音 | edge-tts 合成 + 串行播报（一次只说一句） |
| 猜词游戏 | 纯状态机 + 大模型决策 |
| 舞台页 | 给 OBS 的浏览器源，画形象、词板、选项 |
| 管控台 | 你自己看的界面：现场、手动测试、数据、设置、日志 |

关键设计：每一项都能单独自测，四套自检共 366 项。

---

## 三、为什么做这个

我看了很多虚拟主播，形象一个比一个精致，但**"反应"是死的**：

- 弹幕照念，不管说什么都是同一句"谢谢宝宝"
- 礼物只会说谢谢，送一块和送一万没有区别
- 观众刷完就走，因为没有"留下来的理由"

所以我把重点放在两件事上。

**第一，打赏要分级。** 让人一眼看出"她注意到我花了多少钱"。五档金额对应五套动作、表情、特效、台词，连刷按累计金额升档。

**第二，不花钱的观众也得有事干。** 猜词游戏就是给他们的：不用送礼，发个数字就能参与，而且答案在他们手里——"我们合谋骗她"比单纯看表演有意思。

## 四、怎么跑起来

### 第一步：环境

```powershell
git clone https://github.com/ejekess/ds-live--streaming.git
cd ds-live--streaming
npm install
node src/index.mjs
```

只有两个依赖，没有构建步骤。

看到这两行就成了：

```
舞台（OBS 浏览器源）： http://127.0.0.1:8787/avatar
管控台：               http://127.0.0.1:8787/admin/
```

### 第二步：接进 OBS

来源 → `+` → **浏览器**：

| 字段 | 值 |
| --- | --- |
| URL | `http://127.0.0.1:8787/avatar?bg=gradient` |
| 宽高 | 1920 × 1080 |

背景透明，叠在自己的画面上即可。**不要用显示器捕获**，那会把抓取窗口一起推出去。

### 第三步：接真实弹幕

默认用的是 mock 剧本（假弹幕），方便调试。要接真直播间：

```powershell
node tools\live.mjs 你的房间号
```

它会自动切到 cdp 源、写入房间地址、把礼物门槛降到 T1。

重启服务，日志出现这行就通了：

```
[cdp] 已挂上推送信道： wss://webcast100-ws-web-...
```

**两个必须注意的点**：

1. **要扫码登录一次**。匿名访问只能看视频，弹幕通道不建立——这点我卡了很久。登录态会存进 `data/browser-profile`。
2. **房间地址只有开播后才有**。没开播时 `live.douyin.com/xxx` 会跳回广场首页。

### 第四步：玩一局

管控台「猜词小游戏」→ 开一局。

观众在直播间发数字就行：

| 阶段 | 发什么 |
| --- | --- |
| 选题 | `1` / `2` / `3` 挑一个问题 |
| 回答 | `1`-`4` 选答案，`0` 表示不确定 |

![选题](screenshots/game-2-pick.png)

五轮之后揭晓答案：

![揭晓](screenshots/game-4-reveal.png)

## 五、设计上最花时间的几个决定

这部分是我觉得真正值得说的。

### ① 为什么用"浏览器旁听"而不是自己连抖音

现成方案都是自己算签名去连抖音的 WebSocket，但签名算法平台一改就全废。

我反过来做——**用本机浏览器打开直播间，让它自己握手，我们只旁听数据帧**。签名、心跳、登录态都由浏览器处理，我们只管解 protobuf。代价是多一个窗口，换来的是不怕平台改签名。

### ② 为什么答案不能进模型

反向猜词的关键是"她不知道答案"。这件事我用**数据结构**保证，不是靠提示词：

```
答案存在游戏对象里 → 快照在揭晓前是 null → 台词里根本没有这个词
```

给舞台画面用的字段刻意叫 `displayWord`，不叫 `word`——防止有人顺手把它拼进 prompt。

同理，模型能做决策，但**没有结束游戏的权力**：它只输出"我猜是 XX"，对错由程序比对，猜对才提前结束。

### ③ 为什么语音要排队

第一版是"合成完就播，下一条来了直接顶掉"，观众看到的是**字跳到下一句、声音卡在上半句**。

改成串行队伍：一次只说一句，说完才说下一句，气泡和音频同时出现。代价是延迟几秒，但"晚说一句"比"说半句被掐"好得多。

### ④ 为什么给游戏预留额度

大模型有每日调用上限。测试时发现：直播间弹幕一多，闲聊把额度吃光，**猜词决策一次都排不上**——游戏照常跑，只是从"她在思考"退化成"她一直问到底"，还不报错。

修法是给游戏预留 20%：闲聊用到 80% 就停。这类"静默退化"比崩溃难查得多。

### ⑤ 为什么逻辑要拆成纯状态机

演出、语音、游戏三套时序会打架。写在一个大函数里，加一个功能就踩坏另一个。所以拆成：

```
纯状态机（算逻辑，不碰时间不碰网络）
    ↑ tick 驱动
服务层（管定时器、管副作用）
    ↑ 钩子
编排器（决定说什么、画面画什么）
```

状态机能单测——`verify-reverse.mjs` 里 154 项全是纯逻辑，跑一次不到一秒。

### ⑥ 为什么舞台要能自检版本

OBS 浏览器源会**缓存页面**，代码改了不重载，于是"服务端跑新逻辑、页面是三天前的 JS"，还不报错。

后来加了个版本号：把 `src/stage/` 下文件的修改时间算成短 hash，页面每 10 秒问一次，变了就自己刷新。

## 六、踩过的坑

全都是"不报错但静默失效"的：

| 现象 | 真因 | 怎么发现的 |
| --- | --- | --- |
| 抓到帧却解不出事件 | 抖音把 gzip 报文标成 `pb`，我信了字段名没解压 | 把首帧存下来 hexdump，看到 `1f 8b` 魔数 |
| 开场动画从来没出现过 | 分发钩子时漏转发 `onStart`，事件发了没人接 | 截图时发现 DOM 里没有 `starting` 类 |
| 页面全超时但接口正常 | 父进程退出后日志管道写满，事件循环被堵死 | 逐个接口测响应时间，发现只有静态页挂 |
| 改了代码页面不更新 | OBS 浏览器源缓存页面 | 加了版本自检 |

共同点：**光看代码看不出来，必须真跑一遍**。

## 七、常见问题

| 现象 | 先查这里 |
| --- | --- |
| OBS 黑屏 | 浏览器直接开 `/avatar` 能看不？不能就是服务的问题 |
| 抓到帧但没弹幕 | 是不是没登录？看日志有没有"已挂上推送信道" |
| 她不回话 | 弹幕打分没到阈值（默认 7 分），日志会写"未达阈值" |
| 有气泡没声音 | OBS 里那个源要勾「控制音频」，混音器里不能静音 |
| 游戏开了没反应 | 阶段对不对：选题只认 1/2/3，回答才认 1-4 |
| 她一直问不猜 | 大模型额度用光了，看管控台「数据」页或 `/api/state` 的 `brain` |
