# 创作说明

**为什么选这个**：看了一圈虚拟主播，形象精致但"反应"是死的——礼物只会说谢谢，送一块和送一万没区别。真正让人愿意刷礼物的，是"她知道你花了多少钱"。所以核心做打赏分级：五档金额换五套动作表情。猜词游戏则给不花钱的观众一个开口的理由。

**需求分析**（花时间最多）：动手前列了四条硬约束。①不能卡——演出、语音、游戏三套时序会打架，拆成纯状态机+定时器，逻辑可单测；②不能烧 token——输入输出限长、双上限、6 秒超时，还得给游戏预留额度，否则闲聊会把猜词调用吃光；③不能碰版权——点歌做完直接停用；④不能被弹幕注入——模型只拿纯文本、无工具，答案和流程控制都在宿主代码里。

**AI 工具**：全程 DeepSeek Harness 结对。我定架构和取舍（"答案不能进 prompt""模型不能有结束权"），它写实现和自检。

**踩坑**：都是不报错但静默失效——抖音把 gzip 标成 `pb`，我信了字段名，解出 0 条；钩子漏转发，开场动画从没显示过；日志管道写满，整个服务卡死。只有真跑一遍才暴露。

**发布**：标题《我给虚拟主播做了个"会心疼钱"的大脑》，小红书首发，B 站发完整演示。
