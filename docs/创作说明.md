# 创作说明

**为什么选这个**：虚拟主播形象都精致，但"反应"是死的——礼物只会说谢谢，送一块和送一万没区别。让人愿意刷礼物的，是"她知道你花了多少钱"。所以核心做打赏分级，五档换五套演出；猜词游戏给不花钱的观众一个开口的理由。

**需求分析**：四条硬约束。①不能卡：演出、语音、游戏三套时序会打架，拆成纯状态机加定时器；②不能烧 token：限长、双上限、超时，还要给游戏预留额度，否则闲聊会把猜词调用吃光；③不能碰版权：点歌做完直接停用；④不能被注入：模型只拿纯文本、无工具，答案和流程都在宿主代码里。

**AI 工具**：DeepSeek Harness 结对，我定架构和取舍（"答案不能进 prompt""模型不能有结束权"），它写实现和自检。

**踩坑**：都是不报错但静默失效——抖音把 gzip 标成 `pb`，我信字段名解出 0 条；钩子漏转发，开场动画从没显示过。只有真跑才暴露。

**发布**：《我给虚拟主播做了个"会心疼钱"的大脑》，小红书首发。
