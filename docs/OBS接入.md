# 把鲸鱼娘放进 OBS

目标：`http://127.0.0.1:8787/avatar` 这一页在 OBS 里是一层**透明**的画面，
你的摄像头、游戏、背景图都在它下面。

---

## 一、加浏览器源

1. OBS 右下「来源」→ `+` → **浏览器**。
2. 名称随便（比如 `鲸鱼娘`）。
3. 填：

| 字段 | 值 |
| --- | --- |
| URL | `http://127.0.0.1:8787/avatar` |
| 宽度 | `1920` |
| 高度 | `1080` |
| 使用自定义帧率 | 勾上，`60`（机器吃力就 30） |

4. **自定义 CSS** 留空即可（页面本身已经是透明底）。
   如果你的 OBS 版本仍然显示黑底，往里填这一句：

   ```css
   body { background-color: rgba(0, 0, 0, 0); margin: 0px auto; overflow: hidden; }
   ```

5. 勾上「**场景激活时刷新浏览器**」——切场景回来时能自动重连，不用手动刷新。
6. 「关闭源时关闭」保持**不勾**（关掉再打开能复用页面，启动更快）。

---

## 二、调尺寸和位置

页面里的形象大小由 URL 参数控制，比在 OBS 里缩放更清晰：

| 参数 | 作用 | 例子 |
| --- | --- | --- |
| `h` | 形象高度（px） | `/avatar?h=900` |
| `corner` | 贴哪个角：`br` `bl` `tr` `tl` | `/avatar?corner=bl` |
| `feed` | 是否显示左下弹幕流水，`0` 关掉 | `/avatar?feed=0` |
| `hint` | 是否显示右下角提示，`0` 关掉 | `/avatar?hint=0` |

不传 `h` 时按视口高度的九成自动算，1080p 下大约 970px。

**建议的两种排法：**

- **她占右边**：`corner=br&h=900`，左边留给游戏画面或摄像头。
- **她占左边**：`corner=bl&h=900`，配合下方弹幕流水，像传统虚拟主播的版式。

把浏览器源拖到画面外一点、或用「变换 → 编辑变换」微调，都不会糊——
它是按真实分辨率渲染的。

## 三、关于声音

**当前版本没有语音。** 形象会动、会说气泡文字、会做动作，但不出声。

要加语音有两条路，都不在这个版本里：

1. **浏览器 TTS**：在 `src/stage/stage.js` 里用 `speechSynthesis` 念 `msg.line`。
   优点是不用额外服务；缺点是音色取决于系统、且中文音色在部分机器上很难听。
2. **服务端 TTS + 音频播发**：服务端调 edge-tts / 火山 / 阿里云合成 wav，
   舞台页用 `<audio>` 播放。音质好得多，但要配 Key、要处理播放队列。

OBS 的浏览器源可以捕获页面音频（源属性 → 音频 → 输出音量），所以两条路都能进直播。

## 四、常见问题

**画面是黑的 / 看不到人**

- 先直接用浏览器打开 `http://127.0.0.1:8787/avatar` 看。能看见 → OBS 的问题。
- 看不见 → 看管控台「日志」，通常是 `pet.patched.js` 没生成（跑 `node tools/patch-pet.mjs`）。

**上一场的内容还停在画面上**

- 勾「场景激活时刷新浏览器」，或在 OBS 里右键该源 → 刷新页面。

**动画卡顿 / 掉帧**

- OBS 设置 → 视频 → FPS 降到 30。
- 浏览器源的自定义帧率也降到 30。
- 这台机器同时在跑 Live2D 渲染和编码，笔记本核显会比较吃力。

**形象被切掉一半**

- `h` 给太大了。1080p 场景里 `h=900` 是安全值，`h=1000` 以上底部的桌面大概率出画面。

**换了显示器 / 分辨率后位置全乱**

- URL 里的 `h` 写死像素就会这样。要么用默认（按视口自动算），
  要么在 OBS 里把画布缩放设成统一比例。

---

## 五、和直播软件一起跑的顺序

1. 先 `node src/index.mjs`（服务起来，舞台页可访问）。
2. 再开 OBS，加载浏览器源。
3. 最后在直播平台点「开始直播」。

反过来也行，但先起服务能避免 OBS 里看到一片空白然后怀疑人生。
