# 开播测试流程

从零到"在抖音直播间里玩一局猜词"，按顺序做。

预计 20 分钟，其中真正踩坑的地方标了 ⚠️。

---

## 阶段 0：开播前检查

| 检查 | 怎么查 | 不通过会怎样 |
|---|---|---|
| 抖音实名认证 | 抖音 App → 我 → 设置 → 账号与安全 | 开不了播 |
| 电脑直播权限 | 打开直播伴侣 → 能否点「开始直播」 | 按钮是灰的 |
| 服务在跑 | `http://127.0.0.1:8787/api/state` 有返回 | OBS 黑屏 |

---

## 阶段 1：先开播，拿到房间号

> ⚠️ 房间地址**只有开播后才有**，所以这一步必须在最前面。

1. 打开直播伴侣：`D:\抖音直播\webcast_mate\直播伴侣 Launcher.exe`
2. 手机扫码登录
3. 随便加一个摄像头画面（先能开播就行，后面再换成 OBS 画面）
4. 点「开始直播」

拿到房间号，两种方式：

- 直播伴侣里点「分享」→ 复制链接
- 或者电脑浏览器打开 `https://live.douyin.com/`，搜自己的昵称，点进直播间，地址栏里那串数字就是

```
https://live.douyin.com/123456789
                        └──┬──┘
                        房间号
```

**先别急着配置**，继续往下走完 OBS 那步再一起重启。

---

## 阶段 2：OBS 做画面

1. 打开 OBS：`D:\OBS-Studio-32.1.2-Windows-x64\bin\64bit\obs64.exe`
2. **来源** → `+` → **浏览器**
3. 名字随便，确定后会弹出属性窗口：

   | 字段 | 值 |
   | --- | --- |
   | URL | `http://127.0.0.1:8787/avatar?bg=gradient` |
   | 宽度 | `1920` |
   | 高度 | `1080` |

   勾上「场景激活时刷新浏览器」

4. 再加一个你的摄像头 / 采集卡来源，拖好图层
5. 右下角点 **「启动虚拟摄像机」**

> ⚠️ 如果浏览器源是黑的，先确认服务在跑，再右键那个源 → 刷新。

---

## 阶段 3：直播伴侣换成 OBS 画面

1. 直播伴侣 → 画面来源 → **摄像头**
2. 设备选 **`OBS Virtual Camera`**
3. 现在直播伴侣里看到的应该就是 OBS 合成好的画面（鲸鱼娘 + 你）

---

## 阶段 4：接上弹幕（关键一步）

```powershell
cd D:\space\deepseek\douyin
node tools\live.mjs 123456789     # ← 换成你的房间号
```

它会做三件事：切到 cdp 源、填房间地址、把礼物门槛降到 T1（方便测）。

然后重启服务：

```powershell
$c = Get-NetTCPConnection -LocalPort 8787 -ErrorAction SilentlyContinue
if ($c) { Stop-Process -Id $c.OwningProcess -Force }
Start-Process node -ArgumentList 'src/index.mjs' -WorkingDirectory 'D:\space\deepseek\douyin' `
  -WindowStyle Hidden -RedirectStandardOutput 'logs\server.log' -RedirectStandardError 'logs\server.err.log'
```

> ⚠️ 一定要用 `-RedirectStandardOutput`。直接在终端里 `node src/index.mjs` 再关终端，
> 日志管道会断，进程会卡死（吃过这个亏）。

### 验证抓取成功

```powershell
Get-Content logs\server.log -Tail 20
```

必须看到这一行：

```
[cdp] 已挂上推送信道： wss://webcast100-ws-web-...
```

再查一下有没有数据进来：

```powershell
node -e "fetch('http://127.0.0.1:8787/api/state').then(r=>r.json()).then(j=>console.log('帧',j.source.frames,'| 事件',j.source.events))"
```

`帧` 和 `事件` 在涨 = 通了。

> ⚠️ 抓取会开一个 Edge 窗口显示你的直播间。**别最小化它**（会节流），放后台或副屏即可。
> 它自带静音，不会有回声。

---

## 阶段 5：测游戏

打开舞台页（Ctrl+F5 强制刷新）：

```
http://127.0.0.1:8787/avatar?bg=gradient
```

打开管控台：

```
http://127.0.0.1:8787/admin/
```

### 手动开一局（推荐先这样测）

管控台 → 「猜词小游戏」→ **开一局**

应该立刻看到：

- 左边词板显示答案
- 底部三个候选问题

### 用手机小号投票

| 你发 | 应该发生 |
|---|---|
| `1` / `2` / `3` | 选题成功，她念出那个问题 |
| `1` `2` `3` `4` | 回答阶段投票，卡片上票数 +1 |
| `0` | 弃权，不计入 |

> ⚠️ **阶段要对**。选题阶段只认 1/2/3；回答阶段才认 1-4。

### 测礼物触发

送一个最小的礼物（小心心就够，门槛已经是 T1）。

应该自动开局，她说「第 1 轮，你们想让我问什么」。

### 看模型有没有参与

```powershell
node -e "fetch('http://127.0.0.1:8787/api/state').then(r=>r.json()).then(j=>console.log(j.brain.llm))"
```

`calls` 在涨 = 模型在决策。

**每轮结束她应该停顿 1~3 秒**（在等模型想），然后要么继续问、要么说「我猜是XX」。

---

## 阶段 6：看数据

管控台 → 「数据」页

| 指标 | 说明 |
|---|---|
| 礼物 / 抖币 | 这次测试送了多少 |
| 游戏局数 / 轮数 | 跑了几局 |
| 投票人次 | 一共几票 |
| 参与人数 | 去重后的观众数 |

---

## 收尾（重要）

```powershell
node tools\live.mjs off
```

把 `minTier` 改回 4、`cooldown` 改回 120 秒、源切回 mock。

> ⚠️ **不改回去的话，每个小心心都会开一局游戏**。

然后重启服务。

---

## 出问题先看这里

| 现象 | 最可能的原因 | 处理 |
|---|---|---|
| OBS 黑屏 | 服务没跑 / 卡死 | 浏览器直接开 `/avatar` 试试；看 `logs\server.log` |
| 服务卡死（页面超时但 API 正常） | 日志管道断了 | 用 `-RedirectStandardOutput` 重启 |
| 抓不到弹幕 | 房间号错 / 没开播 | 用 `node tools\live.mjs status` 确认 roomUrl |
| 不会开局 | 礼物没到门槛 | `minTier` 调 1 |
| 开了局但没票 | 观众不知道规则 | 开口喊一句：「想玩的扣 1，屏幕上出选项大家投票」 |
| 她一直问不猜 | 模型额度用光 | 看 `brain.llm.budget.usedToday` |
| 词板不显示 | 页面是旧版 | Ctrl+F5 |

---

## 一句话总结

```
开播拿房间号 → OBS 加浏览器源 + 虚拟摄像机 → 直播伴侣选 OBS Virtual Camera
→ node tools\live.mjs <房间号> → 重启服务 → 看日志"已挂上推送信道"
→ 管控台开一局 → 小号发 1/2/3 → 看数据 → node tools\live.mjs off
```
